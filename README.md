# 基于opencv与qt的简易人脸识别项目
一款基于opencv与qt的简易人脸识别项目，四川大学编程实战课程个人开发作业，参考部分博客以及相关项目完成
## 使用说明
在首页可以录入照片与姓名，采集照片后进入训练，通过训练后即可开启人脸识别功能
## 项目使用的库
### oepncv
Opencv（Open Source Computer Vision Library）是一个基于开源发行的跨平台计算机视觉库，通过调用相关封装函数能做到摄像，简单训练以及人脸识别的功能，详细内容可参考[Opencv官方文档](https://docs.opencv.org/4.x/d9/df8/tutorial_root.html)
### qt
qt 是一个使用 C++编写的跨平台应用程序框架,使用实例化继承于 QWidget 的 MyWin 类对象创建顶级窗口，添加绘画事件 paintEvent，键盘控制事件 keyPressEvent、keyReleaseEvent，以及时间事件 timerEvent设计应用首页;通过给按钮，文本框绑定事件来做到用户点击按钮可以通过调用相关函数执行相关功能。详细内容可参考[qt官方文档](https://doc.qt.io/all-topics.html)
